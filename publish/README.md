# MyVault

**Δωρεάν πρόγραμμα αποθήκης για μικρά καταστήματα. Λειτουργεί χωρίς internet.**

**Free stock manager for small shops. Works completely offline.**

### Πώς το εγκαθιστώ; / How do I install it?

1. Κατεβάστε το `setup.exe` από τον παραπάνω σύνδεσμο.
2. Ανοίξτε το. Τα Windows μπορεί να εμφανίσουν μια προειδοποίηση επειδή το
   πρόγραμμα είναι καινούριο — πατήστε **Περισσότερα** και μετά
   **Εκτέλεση οπωσδήποτε**.
3. Διαλέξτε τη γλώσσα σας στην πρώτη οθόνη και πατήστε **Επόμενο**.

<br>

1. Download `setup.exe` from the link above.
2. Open it. Windows may show a warning because the program is new — click
   **More info**, then **Run anyway**.
3. Pick your language on the first screen and press **Next**.

## Τι κάνει / What it does

- Καταχωρείτε προϊόντα με **όνομα, τιμή, ποσότητα και barcode**. Μόνο το όνομα
  είναι υποχρεωτικό.
- Προσθέτετε **έως 5 δικά σας στοιχεία** — μέγεθος για ρούχα, ηλικία για
  παιχνίδια, ημερομηνία λήξης για μίνι μάρκετ.
- **Αναζήτηση** με όνομα, barcode ή κατηγορία. Δουλεύει και με σαρωτή barcode.
- Ειδοποιήσεις όταν κάτι **τελειώνει**, σύνολα αξίας αποθέματος, εισαγωγή και
  εξαγωγή σε Excel (CSV).
- **21 γλώσσες**, φωτεινό και σκούρο θέμα, χρώματα και μεγέθη κειμένου.

<!-- markdownlint-disable-next-line MD033 -->
<br>

- Add products with a **name, price, quantity and barcode**. Only the name is
  required.
- Add **up to 5 details of your own** — size for clothes, age range for toys,
  expiry date for a mini-market.
- **Search** by name, barcode or category. Works with a barcode scanner.
- Low-stock warnings, stock value totals, and import/export to Excel (CSV).
- **21 languages**, light and dark themes, colours and text sizes.

## Τα δεδομένα σας / Your data

Το MyVault **δεν συνδέεται ποτέ στο internet**. Δεν υπάρχει λογαριασμός, δεν
υπάρχει cloud, δεν στέλνεται τίποτα πουθενά. Όλα τα προϊόντα σας μένουν σε ένα
αρχείο στον δικό σας υπολογιστή, και μπορείτε να κρατάτε αντίγραφα σε στικάκι
όποτε θέλετε.

MyVault **never connects to the internet**. There is no account, no cloud and
nothing is sent anywhere. Everything you enter stays in one file on your own
computer, and you can back it up to a USB stick whenever you like.
